# Node.js HTTP/2 and TLS wave (15 GHSAs): cross-connection heap reads and mTLS policy bypass

Source: hourly offensive-security scan of GitHub Security Advisories, 2026-11-11T21:32Z coordinated wave (Node.js core package; bands span 22.x, 24.x, 26.x with several legs narrowed to 24.22.0+/26.9.0+). The updated-feed sweep after 16:10Z was Storm/Batik re-listings plus Red Hat backfills only; this 21:32Z wave is the day's center of gravity.

Fifteen advisories on the Node.js HTTP/2, TLS, and zlib stack, nearly all reachable by an **unauthenticated remote client**, and three of them are cross-connection memory reads: one leaks other connections' heap (including TLS private keys) into your own response body, one leaks other connections' response buffers on stream teardown, and a trio defeats per-host and per-policy TLS authentication by abusing session state rather than breaking crypto. If your target terminates HTTP/2 or mutual TLS in Node, this page is a standing probe battery.

## Why this matters for operators

- **Handler shape is the vulnerability predicate.** Half this wave fires only for specific handler patterns, not specific frameworks: `res.flushHeaders()` before body end + non-empty `res.end(chunk)` (123864), handler responding before the body ends (123863), `respondWithFile()`/`respondWithFD()` (123874, 123875), attacker-controlled value into `altsvc()` (123828), `deflate.params()` (123862), SNICallback/OCSP/newSession hooks (126051). When fingerprinting a Node service, classifying the **handler shape** of each route (does it respond early? does it stream files? does it echo bodies? which TLS hooks are registered?) predicts exploitability better than the version banner. These are whitebox greps for code review and blackbox timing/response behaviors for external triage.
- **Pair every leak with an echo sink.** The read primitives only pay out where a route echoes or stores what it received (123864 explicitly requires a body-echoing route for read-back). Recon rule on any Node front-end: enumerate routes that reflect request bodies, store them for later display, or parse multipart/JSON and re-emit; they are the exfil channel for every heap-disclosure bug in the family. The same pairing rule already lives on this wiki for scanner telemetry and log viewers; here it is protocol-level.
- **TLS session and SNI state is an authorization input, and it mutates.** Three independent legs (123872, 123867, 123877) break per-host and per-policy mTLS **without touching crypto**: renegotiation swaps the servername under an existing authenticated session; a CA-only SNI context silently keeps the default CA because the install path short-circuits when no server cert is configured; an agent session-cache key that omits the CA dimension lets TLS 1.3 resumption launder a broader trust decision into a stricter request. Decision battery for any Node mTLS terminator: (a) authenticate to the permissive vhost, then renegotiate/reuse toward the strict one; (b) enumerate `addContext` SNI contexts and test each with default-CA vs protected-CA clients; (c) as a client, request the same origin with `ca` omitted then `ca: []` and diff `authorized`. Sibling genealogy: the Oct 14 NGINX forged-session-state mTLS bypass (session state as authorization input) and the Oct 8 hMailServer local-connection trust exemptions.
- **Fuzz the lifecycle/teardown state machine, not just the grammar.** Six H2 legs live in teardown and shutdown transitions: respond-before-body-end (123863), write-queued-across-free (123874, 123866), cancel-mid-file (123875), protocol-error-during-shutdown (123865), unaccounted DATA queue (123868). The canonical frame grammar is fuzzed everywhere; GOAWAY/RST_STREAM/timeout/disconnect interleavings are not. Probe ladder on a lab server: send `GOAWAY(NO_ERROR)` then a malformed frame; `RST_STREAM` a backpressured response mid-write; kill the TCP peer during `params()`/file streaming. And note the genealogy tell: 123863 and 123865 are both **incomplete fixes** of earlier CVEs (2024-27983, 2026-48937) where the fix covered one state of the machine. When a protocol DoS/UAF is patched, re-fuzz the sibling transitions; a vendor that fixed "one order of operations" has not fixed the state machine.
- **Budget enforcement must see every queue.** The 123868 leg is the cap-semantics lesson again: `maxSessionMemory` exists, is configured, and does nothing because the receiving queue is charged to a counter it never feeds. For any product with resource-limit knobs, prove the knob changes observable behavior (connection count vs memory retained per cheap unit of traffic) before trusting it; the wire-cost-to-retained-cost ratio (~1:11 here) is a cheap amplifier for any later slowloris-style work.
- **Error-message sinks leak environment secrets.** 123871 emits proxy credentials into stderr/log-aggregation because four formatter paths missed a redaction fix. For red-team log-hunting and for bug bounty report quality: `grep -r "ERR_" node_modules`-style sink checks and simply **crashing the app on purpose in a lab** (bad proxy URL, bad config) shows what lands in container logs. Crash-report and log-aggregation pipelines are a standing credential-harvest target on shared platforms.
- **Permission-model boundary is checked once, at the root.** 123829 is the grant-at-entry vs event-at-depth gap; generalizes to any watcher/recursive-walk API under a sandbox: validate on every emitted path, not on the invocation argument.

## Validation workflow (authorized labs only)

!!! warning "Owned Node servers only; no production heap reads"
    Run against Node versions you control in lab. All proofs bounded to synthetic data: your own key material as the leak marker, synthetic response bodies, disposable file-serving routes. Never attempt cross-tenant reads on shared infrastructure.

1. **Version and shape triage:** banner the runtime (`server` header, error shapes, `process.version` via any debug route); whitebox where possible, grep handlers for `flushHeaders`, `respondWithFile`, `respondWithFD`, `altsvc(`, `params(`, `SNICallback`, `OCSPRequest`, `newSession`, `addContext`.
2. **Leak-with-echo pairing:** on a lab server with an echo route, start a second connection carrying a marker secret (your own disposable key), then drive the re-entrancy shape (slow body + early `flushHeaders`) and grep the echo output for marker bytes. Positive control on the vulnerable build, negative on the fixed one.
3. **mTLS policy matrix:** lab server with two SNI hosts, one permissive client CA, one protected CA (and one CA-only context with no server cert). Attempt: permissive-cert client reaches protected host via TLS 1.2 renegotiation; default-CA client reaches the CA-only context host; agent `ca`-omitted-then-`ca:[]` reuse for the same origin. Evidence = authorization verdicts per cell, with cert subjects redacted.
4. **Teardown battery:** against a lab H2 server: GOAWAY-then-malformed-frame; RST_STREAM during a backpressured response; cancel a `respondWithFile()` transfer; one-byte DATA flood on an undrained stream with `maxSessionMemory` set. Evidence = process state transitions, RSS curve per wire byte, CLOSE_WAIT inventory. Crash tests only on owned hosts.
5. **Log-sink harvest:** set a malformed `HTTP(S)_PROXY` with marker credentials in a lab container; capture the `ERR_PROXY_INVALID_CONFIG` text to confirm the sink; on real engagements, check what the aggregation pipeline ingests, never exfiltrate third-party credentials.

## Reporting checklist

- Node major/minor (bands differ per leg: several legs need 24.22.0+/26.9.0+ for remote-driven teardown; others span 22.x).
- For read legs: the handler shape that triggers (flushHeaders-before-body-end, respondWithFile, backpressured teardown), the echo/read-back route, and proof bounded to your own marker data; say plainly whether leaked bytes were yours.
- For mTLS legs: the exact policy configuration assumed (per-host client CAs, CA-only SNI context, agent `ca` usage) and the decision-matrix table; these are config-dependent findings, reproduce with the minimal config snippet.
- For DoS/leak legs: wire-cost-to-retained-cost or crash-rate evidence from a lab server, and whether the configured budget knobs moved the numbers.
- For 123871: the sink list (stderr, container log driver, crash reporter) with credentials redacted to marker strings.
