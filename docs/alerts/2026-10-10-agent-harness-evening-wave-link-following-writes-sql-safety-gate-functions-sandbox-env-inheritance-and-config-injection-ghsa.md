## Why this is durable operator value

1. **Agent write-gates are lexical unless proven otherwise — symlink and spawn are the two universal probes.** Three independent products (phi×2, open-multi-agent) fell to the same two shapes in one wave: (a) plant a symlink (live or dangling) inside the workspace and let prompt injection drive a write through it, (b) ask the harness to spawn a child/sub-agent rooted outside the workspace and write there. Dangling vs existing target matters: existence-based validators accept dangling links, then the write itself materializes the path. The audit kit for any agent framework with a workspace/policy gate: committed-symlink repo canary, dangling-symlink canary, `agent_spawn`-style API with attacker-supplied `workdir`, each paired with a marker file outside the root. This is the same repository-trust genealogy as the mise `.tool-versions` and Entire CLI checkpoint-restore pages — validate-at-check ≠ validate-at-write.
2. **"Read-only" SQL safety gates must be tested against the language's side-effecting read grammar, not just DDL/DML keywords.** Tabularis allowed `setval`/`nextval`/`query_to_xml` inside `SELECT` — the gate parsed the statement as a read while PostgreSQL executed writes through *functions*. Sweep every SQL-safety wrapper (LLM SQL tools, MCP DB servers, reporting "read-only" modes) against the full function surface: sequence mutators, `query_to_xml`/`dblink`/`dblink_exec`, `pg_sleep`, `lo_import`/`lo_export`, `COPY ... TO PROGRAM`, and `SELECT ... INTO`. A keyword denylist is a fingerprint, not a gate.
3. **Sandbox env/network inheritance is a five-minute post-foothold check.** mini-swe-agent's missing `--clearenv` means the model-supplied command sees every host secret. Operator probe for any agent-in-a-box (bwrap, container, VM-lite harness you control scope over): run `env` / read `/proc/self/environ` inside the sandbox and diff against the launcher's environment; check whether the sandbox shares the host network namespace (the exfil channel in the advisory). Record which `*_API_KEY`/`*_TOKEN` names exist — presence, not value, is the finding.
4. **Config-injection through "settings" endpoints that serialize YAML by string interpolation.** 9router turned an authenticated dashboard write into agent-exec RCE: unquoted YAML values + attacker-controlled newlines = new top-level keys, and the injected key (`hooks.post_llm_call` + `hooks_auto_accept`) is itself an execution primitive. Audit rule for every product with a settings→YAML/TOML round-trip: submit values containing `\n`, `"`, and `:` and diff the on-disk config file against the submitted fields; then grep the consumer for settings whose *names* imply execution (hooks, commands, plugins, auto_accept). Second lesson: the pivot target here was an agent config — dashboards that manage agent frameworks are agent-compromise surfaces, no second bug needed.
5. **Emulators/local-dev replicas carry the prod feature (template engines) without the prod trust model.** Floci's unrestricted Velocity MOCK templates is the localstack-class pattern: scan emulator ports in dev/CI environments (10.10.10.x-style tool sprawl) and test template-expression injection (`$util.runtime`, SSTI classics) into any mock/template/transform config surface. Same family as the Template-Engine-as-a-Service class, but reachable *unauthenticated* because nobody threat-models the emulator.
6. **Model/artifact pipelines are archive-and-filename sinks.** The Cohere SDK tar-slip (S3-prefix write → host file write) and slide-maker's manifest-filename traversal both show AI tooling trusting *artifact metadata* (tar members, generated filenames) that upstream tooling would sanitize. Sweep: any pipeline that extracts model archives or writes files named from model/manifest output — test absolute paths, `../`, and symlink members against a temp canary root.
7. **Tenant-id-in-header + check-hostname-not-port + DNS-rebind-at-send: three quick oracle wins on LLM-observability/SaaS panels.** OpenLIT (forged project header reads other tenants' prompts/completions), Mealie (IdP-allowlist ignores port → internal-port SSRF on login), Helicone (creation-time-only URL check → DNS-rebind to internal). The reusable battery for any LLM-observability/multi-tenant panel you have scope over: (a) swap `X-*-Project/Tenant-Id` headers between two throwaway orgs and diff the read APIs; (b) for every outbound fetch (avatar, webhook, integration URL), re-test after DNS change and after port change; (c) treat webhook senders as blind internal scanners via a rebinding resolver on an owned domain.

## Replayable validation boundaries (lab/authorized scope only)

- **Symlink/spawn write battery (owned agent harness only):** disposable workspace + marker dir outside root; committed symlink, dangling symlink, sub-agent `workdir` variants; evidence = marker files created and the tool-call trace. Never steer a third party's agent.
- **Side-effecting-SELECT sweep (own DB lab):** run the denylist'd tool's gate against `setval('own_seq',1)`, `query_to_xml('DELETE FROM scratch LIMIT 0')`, `lo_import` on a temp file, `pg_sleep(0.1)` timing; table gate-verdict vs DB-effect. Use scratch tables only.
- **Sandbox env diff (owned harness):** in-sandbox `env` dump diffed against launcher env; report key *names* present; never exfiltrate values.
- **Settings→YAML injection (own instance):** submit a value with `\n` + a benign top-level marker key, diff on-disk config; if a command-executing key exists, stop at the config diff — never save a live hook payload on shared systems.
- **Header-tenant diff (owned two-org lab):** two throwaway orgs, swapped `x-*-project-id` headers on every read route; evidence = field-presence table, redacted prompt content.
- **Rebind/port SSRF (owned domain + owned internal listener only):** attacker-owned domain with a TTL-1 record flipped to the owned listener between creation and send; port-mutation probe against a lab listener. No cloud-metadata endpoints, no third-party internal ranges.
- **Emulator template check (dev boxes in scope only):** point a MOCK/template field at `$util.encode`-style inert reflection marker first; prove reachability without running destructive commands.
