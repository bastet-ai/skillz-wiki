# Infrastructure hard-coded trust defaults, CMS sandbox escapes, and framework fail-open authz: Central Dogma, mistral.rs, Pimcore, October CMS, Payload plugin, Shopper (12 GHSAs)

Source: hourly offensive-security scan, 2026-09-16 (GitHub advisories published 2026-09-10→14). Six product clusters that share one operator theme: **a default, a fail-open flag, or a framework convenience silently replaces the security control you assume is active**. All validation is lab-only with synthetic canaries and denied sinks; never test ISP/production infrastructure, decrypt retained data, or mutate live systems.

## Durable operator patterns

1. **Silent-fallback credential triad.** When auditing config-driven infrastructure, look for the three-part amplification seen in Central Dogma: constant visible in OSS source, substituted silently when config is absent, and reused across two auth surfaces. The presence/absence of one config key becomes the whole authorized test.
2. **Fail-open-by-omission framework flags.** Payload's `overrideAccess !== false` is a template for a whole bug class: any boolean security control whose *safe* value must be explicitly passed will be omitted by plugin authors. Fuzz custom endpoints with the lowest-privileged session you can mint and check whether protected-field recorders fire.
3. **Blocklist regex ≠ injection defense.** Keyword blacklists around user-controlled SQL fragments are bypassable by design; on any authorized report-builder/BI capability, the test is which *benign* non-blocked construct (`UNION SELECT` of a canary) reaches the database, not which payloads slip through.
4. **Sandbox object inventory beats sandbox rule review.** October CMS's bypasses came from *what was inside* the sandbox (session store, `__call` forwarding, deserialization-fed sinks), not from holes in the Twig policy. Enumerate reachable objects first, then methods.
5. **Media-loader parity checks on inference servers.** mistral.rs proves the OpenAI-compatible surface itself is the SSRF/file-read primitive when fetch has no gate. Compare any vision/audio server against vLLM-style allowlists with owned callbacks, bare-path canaries, and scheme fixtures.

!!! warning "Authorized validation only"
    Use disposable Central Dogma replicas, safe-mode lab CMS instances, synthetic Payload documents and Shopper orders, fake inference servers, and owned callbacks. Never read real documents, forge live sessions on production hosts, or probe shared infrastructure.
